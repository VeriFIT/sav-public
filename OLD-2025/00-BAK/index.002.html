Nástroje


Model checking
  • Spin -- verifikace (nejen) distribuovaných SW systémů, vstupem je specializovaný modelovací jazyk Promela (existují překladače do Promely z některých dalších jazyků)
  • Blast -- verifikace C programů
  • Slam -- verifikace driverů v MS Windows
  • Zing -- nový experimentální model checkeru od Microsoftu
  • Magic a ComFoRT -- modulární verifikace C programů
  • Java PathFinder -- JPF -- verifikace (i testování) Java programů
  • Bandera -- verifikace Java programů
  • SMV -- verifikace HW (specializovaný vstupní jazyk, překladač z Verilogu)
  • RuleBase -- verifikace HW, IBM
  • Forte -- verifikace HW, intel (komplexní prstředí zahrnující i theorem proving)
  • O-in -- verifikace HW, Mentor Graphics
  • Magellan -- verifikace HW, Synopsys

Statická analýza
  • CCured -- statická analýza a run-time kontroly práce s pamětí u C programů
  • Přehled nástrojů pro statickou/dynamickou analýzu C kódu

Theorem proving, SAT solving, SMT solving, rozhodovací procedury

Dynamická analýza
  • CCured -- statická analýza a run-time kontroly práce s pamětí u C programů
  • Purify -- dynamická analýza (založená na instrumentaci binárního kódu) korektní práce s pamětí
  • Valgrind -- dynamická analýza (založená na interpretaci) koretní práce s pamětí vlákny
  • Přehled nástrojů pro statickou/dynamickou analýzu C kódu
